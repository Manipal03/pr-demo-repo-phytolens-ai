# calculator

A tiny calculator, used to demo our Git & GitHub workflow.

## Run it

```
python calculator.py
```

## What works

| Function | Status |
|---|---|
| `add(a, b)` | done |
| `subtract(a, b)` | done |
| `multiply(a, b)` | **missing** - see issue #1 |

## How we work

- `main` is protected. Nobody pushes to it directly.
- Every change starts as an issue.
- Branch names: `type/issue-number-short-description`
- Commit messages: `type(scope): summary`
- Every change lands through a pull request.
